# Codex System Network v1

## Purpose

Turn the Codex of Reality from a collection of pages into an explainable operating architecture. Each registered system declares its role, inputs, outputs, route, and relationships to other systems.

- Living Time Observatory

- Systems Archive
- Remnant Lab

## Rules

1. A system must expose its purpose in direct language.
2. Inputs and outputs must be named.
3. Relationships must be typed and explainable.
4. Personal storage must remain local-first unless explicitly exported.
5. Observation, measurement, report, inference, symbolism, experiment, theory, and unresolved claims remain distinct.
6. No system may silently claim evidence from another system merely because they are connected.
7. Shared calendar and Sphere calculations must use canonical engines rather than duplicated formulas.

## Mission-control behavior

The Living Time Observatory provides the first integrated operations surface. It can inspect the system network, display live local record and quest counts, drive Sphere modes and layers, browse seasonal events from 1000–3000 CE, and open each connected system directly.
