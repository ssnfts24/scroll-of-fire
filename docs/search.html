Search the Codex

One living index for the whole site: every page, the Scroll Library's sections and passages, the Hebrew Lexicon, the Atlas and the Claim Register. Press Ctrl K anywhere on the site to search without leaving the page you are reading.

No question in mind? Open one thing at random from the whole index — a page, a scroll passage, a Hebrew word, a claim.

How this search stays true

In sync by construction. The index is generated from this site's own repository — the same sealed catalog and Scroll data the site is built from — and the generated files are committed beside the pages they describe. The copy served by codexofreality.org and the copy in the GitHub source are the same artifact, sealed by the same hash registry, so the search can never quietly drift from the site.

Hebrew-aware. Vowel marks and cantillation are folded away for matching, so pointed and unpointed spellings meet; lexicon entries are also findable by the author's transliteration and by romanization keys.

Its memory is yours. Recent searches and the results you opened are remembered in this browser only, on this device, to help you pick up where you left off. They are never transmitted, and one control clears them.
