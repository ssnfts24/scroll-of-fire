# Living Strata — next build sequence

The Temporal Onion is the spatial foundation. Build outward in this order so additional features remain meaningful and performant.

## Phase A — shell interaction

Add shell picking and a temporal peel/scrub controller. Tapping a membrane selects that year without changing the 13-Moon coordinate anatomy. Scrubbing backward progressively reveals or peels history; scrubbing forward can reveal future planning shells.

## Phase B — Moon-sector temporal corridors

Selecting Moon 1–13 should illuminate the same Moon sector through every visible year shell. Selecting a day should create a narrower day corridor. This is how historical Pattern-position comparison becomes readable.

## Phase C — trajectory registry

Generalize trajectory rendering behind a registry. Each trajectory declares its provenance and reference frame. Initial trajectories: March equinox, September equinox, June solstice, December solstice, lunar phase/state where supported, Year Gate, passage boundaries, and user-selected custom series.

## Phase D — recurrence and difference lenses

Add compare/reference-year selection, recurrence scoring, difference-only rendering, nearest-match highlighting, uncertainty bands, and explanation metadata. Never mix structural guide lines with evidence trajectories without explicit visual distinction.

## Phase E — Life Atlas projection

Project events, observations, media, places, relationships, projects, and witness records onto their year shell + Pattern coordinate. Semantic zoom should move year → Moon → week → day → hour/event while preserving the same temporal cursor.

## Phase F — visual governor

Centralize camera-aware opacity, label priority, geometry LOD, environment-shell suppression, near/far clipping, interaction budgets, and mobile GPU budgets. Heavy contextual layers must never swallow the selected calendar.
